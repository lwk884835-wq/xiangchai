# 工作路线

> 从「岗察」里拆出来的独立版：只保留**行动路线 + 帮你想路线的 Agent**，用来规划自己的工作和生活。
> 不为了打比赛，没有后端、没有账号；简历 / 面试 / 岗位检索这些求职功能全部砍掉。

## 这是什么

一个能长期看下去的行动路线工具。它只有三件事：

0. **路线助手**（可选）：左边常驻的 Agent，只说「帮我想 / 帮我改」就行——
   它会读你现在的路线、按层级和并行关系帮你建/改/挪任务。**只会改路线**，没有别的功能。
1. **一条线**：一个目标 → 几条并行的方向 → 每条方向下具体的动作。
   - **拖拽**：卡片可以直接拖走（连同子任务和同一串里后面的步骤一起搬）；拖到另一张卡片上 = 变成它的一条**新的并行子任务线**（不接在现有链尾）；跨路线拖拽时右栏会弹出目标路线的结构预览，可以精确选择落到哪张卡片下。
   - **删除**：抽屉里删任务时可以选「只删这条（后面一步自动接回前一步）」或「连后面整串一起删」。
   - **撤回**：勾选、删除、拖拽都在同一个「撤回」按钮里，按钮会显示下一步撤的是什么。
2. **进度**：勾过的任务会亮；父任务勾掉会连带子任务，串行的后面勾掉会带上前面的，所有勾选都能「撤回勾选」。
3. **重点清单**：点任务卡上的图钉，把它钉到页面顶部，随时知道自己最近该推什么。

另外支持多条路线（工作一条、生活一条，随时切换）、导出 Markdown（拿去贴日记 / Obsidian）、
导出/导入 JSON（换电脑、换浏览器时搬数据）。

## 跑起来

```bash
npm install
cp .env.example .env.local   # 填 DEEPSEEK_API_KEY（不填也能用，只是助手不可用）
npm run dev                  # http://127.0.0.1:5174
npm run build                # 产出 dist/，可以直接扔到任意静态托管
```

路线数据不依赖 key，纯手动也能记；只有「路线助手」需要模型。
key 只存在 `.env.local`，由 Vite 中间件 `/api/chat` 转发，不会打进前端产物。

数据全部存在浏览器 localStorage（`work-route-actions-v1`），没有服务端。
换设备就点右栏「导出数据」→ 新设备「导入数据」。

```
src/

  components/action/       路线图 / 任务卡 / 详情抽屉 / 重点清单 / 右栏列表
  components/agent/        路线助手（对话面板 / 气泡 / 输入框）
  lib/tools.ts             助手的工具（读路线 / 改路线 / 载技能）+ system prompt
  lib/llm.ts + dsl.ts      流式对话 + 工具调用兜底
  skills/action-plan/      拆路线的技能手册（写给模型看的规则）
  store/actions.ts         路线数据（扁平节点 + parentId，zustand + localStorage）
  store/chat.ts            对话记录（IndexedDB）
  data/actionSeed.ts       第一次打开时的示例路线
  index.css                设计 token（纸感底色 / 字号 / 阴影 / 动效）
```

## 路线助手能做什么（和不能做什么）

**能**：读当前路线（缩进树 + 每个节点的位置）、按规则建树/改层级/改内容/定重点、载入 `action-plan` 技能手册。
它会遵守约定：任务名写成动作、层级用 parentId、一次调用建整棵树、改层级别整树 replace、换方向新建路线。

**不能 / 没有**：简历、面试、岗位检索、投递、知识库、记忆归档、文件解析——
这些是岗察（求职产品）的功能，这里全部去掉了。

## 没有的东西（故意不做）

- 没有后端、没有账号、没有云同步（数据只在你这台浏览器）
- 没有提醒 / 日历集成（以后有需要再说）

## 约定

- 任务名写成**能执行的动作**（「持续投递并记录日志」），不要口号 / 提醒（「不要放弃」）。
- 连线：**同级之间是 V 型箭头，跨层级是带线的箭头**。
- 每次改完先 `npm run build` 确认类型和产物都过。
