# 想拆

> 想拆：从「岗察」里拆出来的独立版，只保留**行动路线 + 帮你想路线的 Agent**，用来规划自己的工作和生活。
> 不为了打比赛，没有后端、没有账号；简历 / 面试 / 岗位检索这些求职功能全部砍掉。

## 这是什么

一个能长期看下去的行动路线工具。它只有三件事：

0. **路线助手**（可选）：左边常驻的 Agent，只说「帮我想 / 帮我改」就行——
   它会读你现在的路线、按层级和并行关系帮你建/改/挪任务，也能管路线、调顺序、删任务（可选删法）、
   勾选完成、改重点清单。**只会改路线**，没有别的功能。
1. **一条线**：一个目标 → 几条并行的方向 → 每条方向下具体的动作。
   - **拖拽**：卡片可以直接拖走（连同子任务和同一串里后面的步骤一起搬）；拖到另一张卡片上 = 变成它的一条**新的并行子任务线**（不接在现有链尾）；跨路线拖拽时右栏会弹出目标路线的结构预览，可以精确选择落到哪张卡片下。
   - **抽屉内拖动**：子任务列表里的卡片可以拖动调整这一串的顺序，或拖到另一条分线的某一行上并入那条线（只搬这一张卡+它自己的子任务，不带走后面的兄弟）。
   - **删除**：抽屉里删任务时可以选「只删这条（后面一步自动接回前一步）」或「连后面整串一起删」。
   - **撤回**：勾选、删除、拖拽都在同一个「撤回」按钮里，按钮会显示下一步撤的是什么。
   - **复制粘贴**：右键卡片可以复制「这张+子任务」或「这一串+后面步骤」；右键目标卡片粘贴 = 变成它的并行子任务，右键空白处粘贴 = 成为当前路线的新目标；也支持 ⌘C/⌘V。
   - **文件夹**：右栏可以新建文件夹，把路线移进去归纳；文件夹可折叠/删除（删除后里面的路线回到未分类）。
   - **一键清已完成**：卡片右键可清除它下面**整条线都做完**的并行线（连同子树）；只要这条线里还有没做完的，整条保留不动，可撤回。
   - **标记不合适**：卡片右键「这个任务似乎不太合适」——当前卡标红划去，未完成的子任务和后续步骤灰掉/划去，保留记录；可取消标记、可撤回。
   - **新路线自动命名**：新建路线时可以不起名，加了第一个目标卡后，路线名会自动跟着它；手动改名后停止跟随。
   - **右键菜单不越界**：在屏幕边缘的卡片上右键，菜单会按实际尺寸夹进窗口，不会再弹到屏幕外。
   - **正文插图**：目标与目的 / 具体怎么做 / 其他备注都能插图，图片可以插在任意两个字之间；支持按钮选图、直接粘贴截图、拖图进来；点缩略图看大图（图片压缩后存在本地数据里）。
   - **路线链接**：右栏路线悬停可「插入到当天路线」——那条路线的任务会实时展开在当天面板里，蓝色描边；点里面的卡片可直接跳过去改，勾选/改动都写回原路线，原路线变了这里也跟着变。
   - **路线搜索**：右栏顶部可以搜索路线名，路线多了也能快速找回。
   - **面板内找卡片**：路线区右上角有固定浮窗搜索框（往下滚也一直能看到），回车跳到下一张（Shift+回车上一张），命中卡片自动滚到中间并闪烁。
   - **批注小标**：卡片有「其他备注」时右上角显示小图标，点它直接进二级页面看批注；没有批注不显示。钉住的卡片图钉常驻；单行卡片图标横排、批注小标永远贴最右侧，会换行的卡片图标竖排并让**文字环绕**它，右侧空间不浪费。
   - **独立成路线**：卡片右键「独立成一条路线」——把它连同子任务和同串后面的步骤移出来变成一条新路线；原位置**内容照旧保留**，只是这一支套上蓝色描边（本质是链接，两边同步），没有额外的「链接卡」。右键链接卡可「移除这条链接分支」。
   - **复制路线链接**：右栏路线悬停有「复制路线链接」，之后在路线里任意卡片（变并行子任务）或空白处（变新目标）右键粘贴；被链接路线的卡直接显示成普通卡片（没有额外容器），用**粗蓝边**标出来，改动实时同步回原路线。
   - **撤回/重做浮窗**：路线区左上角固定浮窗，撤回和「回到下一步」都能点，撤销多了可以救回来。
   - **粘贴可撤销**：富文本里粘贴的文字/图片可以用 ⌘Z 撤回（输入框自己有撤销栈，不依赖浏览器）。
   - **多分支接下一步**：各并行分支都参与布局宽度，下一条「后续步骤」会自动排到整棵子树右边（卡片允许右移，不再强行对齐列）；各分支末端汇到它左侧同一根竖线再进入。带线的箭头尖会贴住卡片边，最后一段线指向小尖角开口的中央。
   - **其他备注**：每张任务可以写一段自由备注，纯记录用，不参与依赖和勾选。
2. **进度**：勾过的任务会亮；父任务勾掉会连带子任务，串行的后面勾掉会带上前面的，所有勾选都能「撤回勾选」。
3. **重点清单**：点任务卡上的图钉，把它钉到页面顶部；钉父任务会**连带钉上它三层以内的子任务**，取消时也一起摘掉。

另外支持多条路线（工作一条、生活一条，随时切换）、导出/导入 JSON（换电脑、换浏览器时搬数据）。
行动路线本身不导出 Markdown —— 串行/并行关系用 md 表达不清楚，也导不回来，JSON 才是唯一数据格式。

## 跑起来

```bash
npm install
cp .env.example .env.local   # 填 DEEPSEEK_API_KEY（不填也能用，只是助手不可用）
npm run dev                  # http://127.0.0.1:5174
npm run build                # 产出 dist/，可以直接扔到任意静态托管
```

路线数据不依赖 key，纯手动也能记；只有「路线助手」需要模型。
key 只存在 `.env.local`，由 Vite 中间件 `/api/chat` 转发，不会打进前端产物。

数据默认存在浏览器 localStorage（`work-route-actions-v1`）；
开发版/稳定版如果带本地数据 API，会同时落到项目里的 JSON 文件（见下面「MCP」一节），
换设备就点右栏「导出数据」→ 新设备「导入数据」。


## 路线助手能做什么（和不能做什么）

**能**：读当前路线（缩进树 + 每个节点的位置）、按规则建树/改层级/改内容/定重点、载入 `action-plan` 技能手册。
它会遵守约定：任务名写成动作、层级用 parentId、一次调用建整棵树、改层级别整树 replace、换方向新建路线。

**不能 / 没有**：简历、面试、岗位检索、投递、知识库、记忆归档、文件解析——
这些是岗察（求职产品）的功能，这里全部去掉了。

## MCP：让别的 Agent 也能读写你的路线

项目里带了一个 MCP server（`mcp/`），任何支持 MCP 的客户端（DSH / Claude Desktop / Claude Code / Cursor…）
都能直接读和改路线，网页会自动刷新——前端外观完全不变。

- 数据文件：开发版 `data/routes.json`、稳定版 `data/routes-stable.json`（可用 `ROUTE_DATA_FILE` 覆盖）
- 网页 ↔ 文件：开发版走 Vite 的 `/api/routes` + SSE；稳定版走 `scripts/stable-server.mjs` 的同名接口
- 启动/配置/工具清单：见 `mcp/README.md`

> 稳定版（5180）由 Agent 改完自动发布（`npm run release:auto` 会构建 + 重启 + 健康检查）；没带接口时网页自动退回 localStorage，不影响使用。
> MCP 默认优先读稳定版数据文件 `data/routes-stable.json`（刷新一次 5180 后自动生成）。

## 没有的东西（故意不做）

- 没有后端、没有账号、没有云同步（数据只在你这台浏览器）
- 没有提醒 / 日历集成（以后有需要再说）

## 稳定版 vs 开发版

- **稳定版（日常用）**：<http://127.0.0.1:5180/>
  - 由 `releases/current` 里的构建产物提供服务，和开发服务器完全独立
  - 已注册 launchd 常驻：`com.lwk.work-route-stable`（开机自启、挂了自动拉起）
  - 桌面快捷方式：`工作路线-稳定版`（webloc 直接打开；.command 负责兜底启动）
- **开发版（改代码用）**：<http://127.0.0.1:5174/>（`npm run dev`，随时可能变）
- **数据是分开的**：localStorage 按 origin 存。第一次把数据搬到稳定版：
  开发版右栏「导出数据」→ 稳定版右栏「导入数据」；之后日常只用稳定版。
- **发布新稳定版**：`npm run release:auto`（= 从 git HEAD 构建 + 备份稳定版数据 + 重启服务 + 健康检查；
  **不读工作区**，避免把半成品发出去）。平时 Agent 改完会自动跑这个，你只要刷新 5180。
  - 只发一版、不重启：`npm run release:stable`
  - 指定提交：`npm run release:auto -- <git-ref>`
  - 回滚：`npm run release:auto -- <旧提交>`
  - 版本目录 `releases/<时间>-<sha>/`，只保留最近 6 个；服务永远读 `releases/current` 这个软链
- **停止/卸载常驻服务**：`launchctl bootout gui/$(id -u)/com.lwk.work-route-stable`
  （plist：`~/Library/LaunchAgents/com.lwk.work-route-stable.plist`）

## 约定

- 任务名写成**能执行的动作**（「持续投递并记录日志」），不要口号 / 提醒（「不要放弃」）。
- 连线：**同级之间是 V 型箭头，跨层级是带线的箭头**。
- 每次改完先 `npm run build` 确认类型和产物都过。
